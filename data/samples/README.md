# 샘플 기사

개발과 테스트에 쓰는 **가상의 기사**입니다. 회사명, 수치, 날짜, 법령 개정 내용은 모두 지어낸 것이며 실제 사건이나 실제 개정 내용이 아닙니다.

| 파일 | 유형 | 기대 결과 |
|---|---|---|
| `incident_ransomware.txt` | 침해사고 | 원인 여러 개(VPN 미패치, 백업 미분리, 탐지 지연)가 나뉘어 추출되고, 원인별 점검이 이뤄진다 |
| `law_privacy_amendment.txt` | 법·제도 | 변경 조항, 시행일, 적용 대상이 추출되고, 조항별 점검이 이뤄진다 |
| `unrelated_product_launch.txt` | 기타 | 요약만 나오고 "점검 대상 아님"으로 판정된다 |
